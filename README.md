​⚡ VIRGOZKI CONFIG PANEL - CYBERPUNK EDITION
​A modern web-based configuration panel and server monitor featuring a Cyberpunk theme. It is designed for quickly generating various secure VPN tunneling configs, real-time server monitoring, and includes a background audio/video player for an enhanced experience.

​✨ Key Features
​⚡ Multi-Protocol Support: Supports generating configs for VLESS, Trojan, VMess, and Shadowsocks.
​📶 Flexible Transports: Includes options for WebSocket (WS), HTTP Upgrade, XHTTP, and gRPC (with synced paths/service names).
​📊 Real-Time Server Monitor: Live tracking of your IP address, location, server status, latency/ping graph, and server uptime.
​​🎵 Floating Music Player: Features a mini music player (featuring tracks from NEFFEX) that you can drag anywhere on the screen.
​📱 Fully Responsive & Optimized: Works perfectly on both mobile phones and desktop browsers with clear cyberpunk aesthetics and a transparent glassmorphism design.

​🛠️ How to Use
​Clone or download this project to your server or local machine.
​Open index.html using any modern web browser or deploy it via OpenResty / Nginx / Docker.
​Select a Bug Host / Address or use the default hostname from the list.
​Select an SNI / Server Name you wish to use for bypassing.
​Choose your Protocol Type (VLESS, Trojan, VMess, Shadowsocks) and Connection Transport (WS, gRPC, etc.).
​Quickly copy the generated config by clicking the COPY button and import it into your VPN client app (such as v2rayNG, NekoBox, or ZiVPN).

​📂 Project Structure
​index.html - The single file containing the entire frontend layout, CSS styling (Cyberpunk theme), and JavaScript logic for the config generator, monitor, and music player.
